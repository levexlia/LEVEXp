# LEVEX

**LEVEX** — платформа «Жизнь как RPG». Цели и задачи в разных сферах жизни приносят опыт (XP), уровни, награды и навыки. В основе — три опоры: **знания**, **самовыражение** и **помощь другим**.

## Статус v1

Полное видение продукта существует, но мы строим **итеративно**: сейчас здесь только рабочий API-каркас (`/health`) и доменные типы. Модули ниже — дорожная карта, а не реализованный функционал.

## Дорожная карта модулей (черновик, уточняется)

1. Профиль игрока (Player)
2. Сферы жизни (LifeSphere)
3. Цели и задачи (Goal / Quest)
4. Прогрессия: XP и уровни
5. Навыки и дерево навыков
6. Награды и достижения
7. Привычки и ежедневные квесты
8. База знаний / обучение
9. Самовыражение: дневник, творчество, публикации
10. Помощь другим: взаимопомощь, менторство
11. Сообщество и гильдии
12. Статистика и аналитика прогресса
13. Уведомления и напоминания
14. Внутренняя экономика / магазин наград
15. Интеграции (календарь, трекеры, внешние сервисы)

## Структура

```
apps/api         — Fastify API (TypeScript, tsx)
packages/domain  — доменные типы: Player, LifeSphere, Goal, Progression
```

## Запуск

```bash
cp .env.example .env
npm install
npm run start:api   # или npm run dev:api (watch)
curl localhost:3000/health
npm test
```
